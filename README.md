# JavaScript Calculator Web App 🧮

### Web Address :  
[supremecalculator.netlify.app](supremecalculator.netlify.app)

## Overview
This web-based calculator is a comprehensive implementation of a mathematical expression parser and evaluator, built using React. The project demonstrates advanced algorithmic techniques like the Shunting Yard algorithm for handling complex mathematical expressions with proper operator precedence.

## 🌟 Features

### Core Functionality
- Basic arithmetic operations (+, -, *, /)
- Decimal point input
- Percentage calculations
- Sign inversion
- Calculation history tracking

### Advanced Parsing
- Implements Shunting Yard algorithm for expression parsing
- Handles operator precedence
- Converts between infix, postfix, and evaluated expressions

## 🛠 Technologies Used
- React
- JavaScript
- CSS
- Shunting Yard Algorithm
- Postfix Expression Evaluation

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or later)
- npm or yarn

### Installation
1. Clone the repository
```bash
git clone https://github.com/dpatel698/webcalculator.git
```

2. Install dependencies
```bash
cd advanced-calculator
npm install
```

3. Start the development server
```bash
npm start
```

## 📝 Key Algorithmic Implementations

- Shunting Yard Algorithm: Converts infix expressions to postfix
- Postfix Expression Evaluation: Calculates results using stack-based method
- Expression History Tracking: Maintains a list of previous calculations

## 🧪 How It Works
1. Input mathematical expressions
2. Parse expression using Shunting Yard algorithm
3. Convert to postfix notation
4. Evaluate using stack-based method
5. Display result and add to history
